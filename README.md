# File & Folder Explorer

A Python Tkinter-based File and Folder Explorer that allows users to browse and manage files and folders using a graphical interface. The project demonstrates the use of tree structures and recursion to display folder contents.

## Features

- User Login
- Browse existing folders
- Recursively display files and folders
- Tree-view representation of directory structure
- Search files and folders
- Create New File
- Create New Folder
- Rename files and folders
- Delete files and folders
- Refresh directory contents
- Logout
- Graphical User Interface

## Data Structures and Concepts Used

- Tree Data Structure
- Recursion
- File and Folder Traversal
- Searching
- Hierarchical Data Representation

## Technologies Used

- Python
- Tkinter
- Tkinter Treeview
- OS Module

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:
